# Speed-ups

There are nine different rates the game can run at, determined by eight score breakpoints.  For Pytch version, have to pre-synthesise all sounds, and nine is a bit much, so quantise into three buckets.

The "action period" starts at 16 and is decremented by one each time we move into a new score interval, so by the end we're running twice as quickly.  The durations therefore can be 16/16, 13/16, 10/16 of the original full duration.

Sound effects needing this treatment are:

* player-shot
* defender-base-hit
* normal-defender-hit
* special-defender-hit
* shot-hit

(Which leaves

* start-of-game.wav
* player-hit.wav
* end-of-game.wav

to be always the same speed.)
